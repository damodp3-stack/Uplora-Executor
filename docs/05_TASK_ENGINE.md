# Uplora: Task Engine & Adaptive Difficulty System

## 1. Multi-Layer Task Hierarchy
Tasks in Uplora 1B Quest operate across three synchronized time horizons plus high-leverage side quests:

1. **Daily Quests (Tactical Execution)**:
   * Non-negotiable daily output (e.g., Damo's calls, Partner's commits/deployments, Assistant's prospect logs).
   * Direct check-off with instant XP distribution.
2. **Weekly Missions (Strategic Milestones)**:
   * Reset every Monday. Synthesizes pipeline goals (e.g., "Send 4 proposals", "Launch client beta site", "Test new StoreIK pitch").
3. **Monthly Boss Battles (Macro Targets)**:
   * The ultimate month-end hurdle (e.g., "Slay the ₹1,00,000 Target").
   * At month-end, the Boss Battle review calculates % achieved, causes of shortfall, top revenue drivers, and strategic directives.
4. **Side Quests (Opportunity Exploitation)**:
   * Non-blocking optional missions that provide high XP and unlock new revenue avenues (e.g., "Analyze 10 competitor pricing models", "Find 5 unserved e-commerce niches in Coimbatore / Chennai", "Draft 3 StoreIK cold pitch templates").

---

## 2. The Missed Task System & Root Cause Diagnosis
When any team member marks a task as **Not Completed** or allows it to expire past deadline, the system refuses to let it simply disappear or accumulate guilt.

The user is prompted with an immediate, compassionate, yet analytical inquiry:
* 😴 **Time Deficit**: "Did not have enough uninterrupted focus time."
* 📞 **Access Friction**: "Could not reach prospects / phone numbers dead or unanswered."
* 🧠 **Skill / Knowledge Gap**: "Didn't know how to execute the specific step."
* 🔥 **Priority Clash**: "A higher-priority fire or client emergency arrived."
* 🚧 **Technical Impediment**: "Software, hosting, or API tool broke down."
* 😕 **Motivation / Resistance**: "Felt mental resistance, burnout, or procrastination."
* ✍️ **Other**: Custom contextual explanation.

## 3. Dynamic Behavioral Auto-Adaptation Algorithm
Traditional planners assign static goals regardless of human performance. The Quest Engine implements dynamic game scaling:

```
[Target: 20 calls/day] 
   ──> Day 1: 7 calls (Missed: No time)
   ──> Day 2: 8 calls (Missed: Burnout)
   ──> Day 3: 6 calls (Missed: Burnout)
   ──> TRIGGER: Repeated failure threshold (3+ consecutive missed targets)
   ──> AI INTERVENTION: "Founder capacity bottleneck detected. Resetting challenge."
   ──> NEW ADAPTED GOAL: 10 calls/day for 3 days
   ──> SUCCESS (3/3 days completed) ──> Scale up: 12 calls/day ──> 15 calls/day ──> 20 calls/day.
```
* **Principle**: Small consistent wins compound into momentum; chronic failure breeds despair. The engine prevents founder demoralization while preserving relentless upward trajectory.
